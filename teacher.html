📖 How to run this in Zoom / Google Meet

  1. Create a session above and share the session code or link with students (chat or screen).
  2. Students open index.html (or the hosted URL), enter their name + code, and click Join Mission.
  3. Share your screen showing this dashboard so the class can see live scores.
  4. Guide students through Mission 1 (butterfly order), Mission 2 (frog + habitat), then the quick quiz.
  5. When finished, use Close Session or Reset for the next class.
